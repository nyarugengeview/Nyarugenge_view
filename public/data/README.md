# Data files

Register public datasets in `manifest.json`. Place verified or pending files under `statistics/`, `geography/`, or `facilities/`. Keep unavailable registrations metadata-only. See the repository `README.md` for complete CSV, JSON, and GeoJSON examples, source requirements, validation commands, and GitHub Pages workflow.

Never place secrets or personal data in this public directory. Do not label sample values as official. All non-production examples must be explicitly identified as schema examples and remain outside the verified data registry.
