# Nyarugenge View brand assets

The React application serves these files from `public/images/` and links the favicon, Apple touch icon, and web manifest in `index.html`. The asset URLs use Vite's base path so they work both locally and on the GitHub Pages project site.

- `nyarugenge-view-header.png` is the horizontal transparent wordmark used in the top-left header.
- `nyarugenge-view-logo.png` is the complete supplied logo artwork.
- `hero-nyarugenge.jpg` is the supplied Kigali/Nyarugenge city photo used behind the homepage hero text.
- `favicon.ico` and PNG favicons cover browser tabs at small sizes.
- `apple-touch-icon.png` (180×180) and Android icons (192×192 and 512×512) cover mobile home-screen installs.
- `site.webmanifest` describes the installable app icons and theme colors.
