# Import templates

These files are empty structure templates only. They contain no example observations, are not registered in `public/data/manifest.json`, and are not presented as official or demonstration statistics. Replace every `replace-with-*` value with metadata from the dataset's actual publisher before registration. A template with no rows/features is not a usable dataset.

- `csv-template.csv`: header-only table template.
- `json-indicator-template.json`: indicator file structure with no fabricated values.
- `geojson-template.geojson`: empty GeoJSON FeatureCollection.
- `manifest-entry-template.json`: pending-review metadata structure with no fabricated source.
